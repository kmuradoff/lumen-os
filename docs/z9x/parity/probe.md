## Что уже выяснено без устройства: раскладка 157

В прокси вендора (`xgimi.hardware.gmpf@1.0.so` с Z9X) прокси `_hidl_getOutputTimingInfo` (0x16f920) создаёт
reply-лямбду с vtable 0x33ee20; её operator() (0x25e2f0) читает Status, `readBool`, затем `readBuffer(40)`.
40 байт = 7 int `OutputTimingInfo` (user_timing_idx, disp_width, disp_height, curr_timing_idx, curr_hres,
curr_vres, vfreq) + 3 int `stDlpSupportTiming` (timing2dIdx, timing3dIdx, timingMaxVfreqIdx). Порядок полей
в HIDL не доказан (AIDL-двойник объявляет supportTiming первым в полях класса, но пишет его последним):
проба логирует все 10 int и сырые байты. Для сравнения в той же таблице лямбд: 55 = bool + 12, 662 = 16
(совпадает с `Gmpf2Client` и `GmpfClient`).

## Решения по исправлениям 2, 8, 10 (2026-10-30, после живых чтений)

- **2 (EDID 660/661)**: ничего не менять. 661 = 1 на HDMI 2.0, шкала 0/1/2, значения Lumen верны.
- **8 (игра)**: сделано. Строка режима и плитка берут режим из 55 текущего входа (если опция в 55 совпадает с 647),
  пока изменение ждёт применения, 10 с показывается выбранное; блок трапеции и поворота "Турбо" только когда
  647 = 2/3 и 55 говорит "игра включена" (без 55 как раньше); `gameModeOn` для запретов изображения как сток
  (режим 4 или 55 state on). `GameProfile` больше не ждёт "решающего" чтения с 647 = 2/3: раскладка известна.
- **10 (Ultra 120)**: сделано. Строка показывает 157 (`user_timing_idx == 4`), сохранённое значение следует за 157;
  на HDMI включение разрешено при сигнале 662 ниже 62 Гц (как сток), при 62 Гц и выше "недоступно для этого
  контента", при нечитаемом сигнале прежний отказ; после 161 чтение 157 назад. Строка "ещё не проверено" убрана из
  диалога (161(4)/(6) и чтение назад проверены на этом проекторе).
- **175 (яркость п. 12)**: только одно значение (17) в текущем режиме, правило не трогали.

На устройстве новый Projector ещё не проверен: на 1.0.7 он не ставится (пакет `org.lumen.projector` и мосты
приходят только с образом), USB-кабеля к Mac нет, поэтому образ 1.0.8-test2 не собирался и не прошивался.

# Установка Lumen OS на XGIMI Z9X HB

[English version](en.md)

Lumen OS это Android TV 14 на основе LineageOS 21 для XGIMI Z9X HB (модель G0130) с прошивкой XGIMI
V6.16.24. Она заменяет только системный раздел. Прошивку, boot, vendor и калибровку XGIMI она не трогает.
Новые версии потом приходят по Wi-Fi, данные при этом сохраняются.

> [!CAUTION]
> Установка **стирает все данные на проекторе**. Вернуть родную прошивку можно официальным файлом
> прошивки XGIMI V6.16.24 (2,2 ГБ, [скачать с сервера XGIMI](https://product-library.static.xgimi.com/firmware/release/MTK9660_AOSP/dapeng/MTK9660_AOSP_GEMINI_6.16.24_20260428-152516/XGIMI_GOATELEGANT_XR03D.bin)), см.
> [«Откат на сток»](#hb-stock). Скачайте его заранее, до установки.

> [!WARNING]
> **Внимание: это прошивка 6.16.24.** Она только для возврата на сток с Lumen OS. Если ваш проектор пришёл
> с прошивкой V6.17.12 (в меню рядом может стоять версия оболочки GMUI 6.18.x), не ставьте на него 6.16.24, чтобы потом поставить Lumen OS: неизвестно, подходит ли
> старая прошивка к новым платам, на других моделях XGIMI после такого отката переставали работать Wi-Fi и
> Bluetooth.

Установка занимает около 30 минут. Вы вводите несколько команд в терминале, а один шаг в режиме fastboot
(vbmeta) делаете сами, без установщика.

**Как компьютер связывается с проектором.** Пока на проекторе работает обычная система, компьютер
подключается к нему по Wi-Fi: так идут проверка, копирование файлов и команда перейти в режим fastboot.
Кабель USB A–A нужен только в режиме fastboot, для записи: в обычной системе USB-порт проектора работает
для флешек, а в режиме fastboot он становится портом для компьютера. Вставляйте кабель, только когда об
этом скажет инструкция или установщик. Режим fastboot сам не выключается, спешить не нужно.

<a name="hb-need"></a>

## Что нужно

- XGIMI Z9X HB, модель G0130, на прошивке XGIMI V6.16.24. Модель и версию прошивки видно на стоке в
  «Настройки → Об устройстве». Установщик тоже их проверяет и на другом проекторе ничего не делает.
- Сеть Wi-Fi, в которой и проектор, и компьютер. Гостевая сеть, где устройства не видят друг друга, не
  подойдёт.
- Компьютер с macOS, Linux или Windows 10/11 (на Windows установка на проекторе ещё не проверялась).
- Кабель USB A–A, с обеих сторон обычный USB-A.
- 4 ГБ свободного места на компьютере.
- Интернет при первом запуске: установщик сам скачивает у Google Platform-Tools (adb и fastboot, около
  10 МБ) в папку `tools/platform-tools` рядом с собой, проверяет их и работает только с этой копией. Без
  интернета укажите свою папку с adb и fastboot версии 35 или новее: `--platform-tools ПАПКА` (Windows:
  `-PlatformTools ПАПКА`).
- Флешка на случай отката на сток.

На Windows вместо `bash lumen-install.sh` запускайте `lumen-install.cmd`, вместо `--ip` пишите `-Ip`, вместо
`--lang ru` пишите `-Lang ru`, например `lumen-install.cmd check -Ip 192.168.x.y -Lang ru`. Держите папку
установщика на диске самого компьютера (например `C:\lumen`), а не на флешке. Для режима fastboot на кабеле
Windows может понадобиться [Google USB Driver](https://developer.android.com/studio/run/win-usb).

<a name="hb-prepare"></a>

## 1. Подготовьте проектор (10 мин)

1. Подключите проектор к своему Wi-Fi. Если сток предлагает обновление системы, не соглашайтесь:
   скачанное обновление ждёт перезагрузки и мешает установке.
2. Включите отладку. В «Настройки → Об устройстве» нажимайте OK на пункте с номером сборки, пока не
   откроется меню «Для разработчиков». В нём включите «Отладка по USB». На стоке HB это включает отладку
   по Wi-Fi (порт 5555).
3. Запишите IP-адрес проектора. Он виден в сетевых настройках стока, на странице сети Wi-Fi, к которой
   проектор подключён. Его же показывает список устройств в роутере.

Названия пунктов меню на стоке могут немного отличаться, это зависит от языка и версии прошивки.

<a name="hb-files"></a>

## 2. Скачайте файлы (5 мин)

1. Откройте [страницу релизов](https://github.com/kmuradoff/lumen-os/releases) на GitHub и выберите самый
   новый релиз для XGIMI Z9X HB: его тег начинается с `z9x-hb-`. Скачивайте только оттуда, копии на форумах
   и файлообменниках я не проверяю.
2. Скачайте из него четыре файла: образ `lumen-os-hb-<версия>-nogms-system.img`, `SHA256SUMS`,
   `SHA256SUMS.sig` и установщик `lumen-os-hb-<версия>-installer.zip`.
3. Распакуйте архив установщика. Образ и оба файла `SHA256SUMS` положите рядом с `lumen-install.sh`.
4. Откройте терминал и перейдите в эту папку, например `cd ~/lumen`.

Установщик сам проверяет подпись и контрольную сумму образа и не примет файлы другого проектора.

<details>
<summary>Проверить подпись вручную</summary>

```
openssl x509 -in certs/hb/ota.x509.pem -pubkey -noout > lumen.pub
```

```
openssl dgst -sha256 -verify lumen.pub -signature SHA256SUMS.sig SHA256SUMS
```

Вторая команда должна ответить `Verified OK`. Отпечаток сертификата
(`openssl x509 -in certs/hb/ota.x509.pem -noout -fingerprint -sha256`) должен совпасть со строкой
`ota/ota` в файле `devices/goat_elegant/certs/FINGERPRINTS.txt` репозитория:
`8E:47:E4:95:F9:FC:C5:DB:46:4F:52:C5:78:20:9F:DA:3A:9E:47:FF:80:AA:FC:E6:F7:12:5D:2C:51:A9:86:24`.

</details>

<a name="hb-check"></a>

## 3. Запустите проверку (2 мин, ничего не записывает)

Вместо `192.168.x.y` укажите адрес своего проектора:

```
bash lumen-install.sh --lang ru --ip 192.168.x.y check
```

Установщик подключится к проектору по Wi-Fi и проверит модель, прошивку, слот, программы на компьютере и
образ. Ещё он скажет, сделан ли шаг vbmeta: до шага 4 он и не должен быть сделан. В конце должна быть
строка, что проверка пройдена и ничего не записано.

Если установщик пишет «СТОП», найдите его сообщение в разделе [«Если что-то пошло не так»](#hb-problems).

<a name="vbmeta"></a>
<a name="hb-vbmeta"></a>

## 4. Отключите проверку vbmeta (5 мин)

Этот шаг вы делаете сами, установщик команды vbmeta не запускает. Lumen OS не подписана XGIMI, поэтому
проверку системного раздела надо отключить. Так делают для любой GSI, у Google это описано в разделе
[«Requirements for flashing GSIs»](https://source.android.com/docs/core/tests/vts/gsi#flashing-gsis). Сток
после этого шага работает как раньше.

Если adb и fastboot у вас не установлены, берите те, что скачал установщик: вместо `adb` пишите
`tools/platform-tools/adb`, вместо `fastboot` пишите `tools/platform-tools/fastboot` (Windows:
`tools\platform-tools\adb.exe` и `tools\platform-tools\fastboot.exe`).

1. Скачайте со [страницы GSI у Google](https://developer.android.com/topic/generic-system-image/releases)
   любой архив для arm64, например `aosp_arm64`, достаньте из него `vbmeta.img` и положите его в папку
   установщика.
2. Подключитесь к проектору по Wi-Fi:

   ```
   adb connect 192.168.x.y:5555
   ```

   Затем проверьте:

   ```
   adb devices
   ```

   Должна быть строка `192.168.x.y:5555`, которая заканчивается на `device`.
3. Выньте из USB-порта проектора всё, что там вставлено, и соедините этот порт с компьютером кабелем A–A.
4. Переведите проектор в режим fastboot (команда идёт по Wi-Fi):

   ```
   adb -s 192.168.x.y:5555 reboot fastboot
   ```

   Через 20–40 секунд проверьте, что компьютер видит проектор по кабелю:

   ```
   fastboot devices
   ```

   Должна появиться одна строка, которая заканчивается на `fastboot`.
5. Отключите проверку сразу в обоих слотах:

   ```
   fastboot --disable-verity --disable-verification --slot=all flash vbmeta vbmeta.img
   ```

   В ответе должны быть строки `Writing 'vbmeta_a'` и `Writing 'vbmeta_b'`, обе с `OKAY`.
6. Перезагрузите проектор:

   ```
   fastboot reboot
   ```

   Должен загрузиться сток, как обычно, с вашими данными. Если загрузка зависла с вставленным кабелем,
   выньте кабель и нажмите кнопку питания.
7. Выньте кабель и снова запустите проверку (шаг 3). Теперь она должна сказать, что проверка vbmeta
   выключена.

<a name="hb-install"></a>

## 5. Установите Lumen OS (около 10 минут, стирает все данные)

```
bash lumen-install.sh --lang ru --ip 192.168.x.y
```

Чтобы сразу получить Google Play, добавьте к этой команде `--gapps-zip` с файлом MindTheGapps, см.
[«Как поставить сервисы Google»](#hb-google). Данные тогда стираются один раз.

Установщик сам проходит шаги по порядку. Если он где-то остановился, исправьте то, что он пишет, и
запустите ту же команду снова: он продолжит с того же места.

1. Если проверка (шаг 3) уже пройдена, он её не повторяет.
2. Он предложит сохранить приложения и файлы. Если согласиться, он скопирует установленные приложения
   (файлы APK), папки Download, Movies, Music, Pictures, DCIM и Documents в `~/Lumen-backup/<дата>/` на
   компьютере. Данные приложений (вход в аккаунты, прогресс просмотра) так не сохранить.
3. Он скопирует с проектора два файла XGIMI (о них ниже) и сохранит их копию на компьютере.
4. Он ещё раз проверит проектор и образ, покажет, что будет стёрто (приложения, аккаунты, настройки и
   файлы), и попросит ввести `ERASE`. Без шага vbmeta он ничего не запишет.
5. Он попросит вынуть всё из USB-порта проектора и соединить этот порт с компьютером кабелем A–A.
   Сделайте это и нажмите Enter.
6. Дальше он работает без вас: переведёт проектор в режим fastboot, запишет файлы XGIMI и систему,
   отформатирует данные и перезагрузит проектор. В это время не вынимайте кабель и не отключайте питание.
7. Когда установщик скажет, что всё записано, выньте кабель. Если загрузка зависла с вставленным кабелем,
   выньте его и нажмите кнопку питания.

<a name="hb-blobs"></a>

### Два файла с вашего проектора

Выкладывать файлы XGIMI и MediaTek я не имею права, поэтому в образе их нет. Перед записью установщик
копирует два таких файла с вашего же проектора: библиотеку видео MediaTek (без неё нет аппаратного
декодирования видео, а картинка HDMI может зависнуть) и файл настроек звука XGIMI (без него работает только
встроенный динамик). Каждый файл он сверяет с контрольной суммой, а Lumen OS при каждом запуске проверяет
их ещё раз. Файлы ложатся в маленький раздел `z9x_blobs` (4 МБ), копия остаётся на компьютере в
`~/Lumen-backup/hb-blobs-<серийный номер>.img`.

Если установщик пишет, что файл не совпадает с контрольной суммой, значит, файлы вашей прошивки ему
неизвестны. Напишите в [issues на GitHub](https://github.com/kmuradoff/lumen-os/issues) и приложите вывод
установщика. Систему можно поставить и без этих файлов, с параметром `--no-blobs`, но тогда не будет
того, что написано выше.

<a name="hb-first-start"></a>

## 6. Первый запуск

Первый запуск после стирания идёт дольше обычного, до полутора минут. Потом откроется первая настройка:
пульт, язык, Wi-Fi. Пройдите её.

Дальше новые версии Lumen OS приходят по Wi-Fi: проектор сам находит обновление, ставит его, пока вы
смотрите, и просит перезапуск. Данные сохраняются. Пока обновление ставится, до просьбы перезапустить
проектор, не меняйте настройки изображения и трапецию: проектор хранит их в разделе, который обновление
копирует, и изменение в это время пропадёт.

### Как поставить приложения

С флешки:

1. Скопируйте файлы `.apk` на флешку FAT32 или exFAT и вставьте её в проектор.
2. В Lumen Home откройте «Файлы», выберите флешку и нажмите OK на файле `.apk`.
3. Появится название, значок, версия и пометка «Новое» или «Обновление». Нажмите OK ещё раз и подтвердите
   установку.

Подходят обычные `.apk`, не `.apks` и не `.xapk`. Обновления ставятся так же.

<a name="hb-verify"></a>

## 7. По желанию: проверьте установку

1. Откройте «Настройки → Настройки устройства → Об устройстве» и 7 раз нажмите OK на пункте «Сборка».
2. Откройте «Настройки → Настройки устройства → Для разработчиков» и включите «Отладка по USB» (на HB это
   отладка по Wi-Fi).
3. Посмотрите адрес проектора в «Настройки → Сеть и Интернет», на странице вашей сети.
4. Запустите:

   ```
   bash lumen-install.sh --lang ru --ip 192.168.x.y verify
   ```

   Проектор спросит «Разрешить отладку?». Отметьте «Всегда разрешать с этого компьютера» и нажмите OK.

Установщик покажет версию Lumen OS и встали ли файлы XGIMI. Строки с `✓` в порядке. Строки с `!` пришлите
вместе с вопросом. После проверки отладку можно снова выключить.

<a name="hb-google"></a>

## Как поставить сервисы Google

В релизе образ без Google. Выкладывать сервисы Google я не могу, поэтому файл с ними вы скачиваете сами, а
установщик ставит его в отдельный раздел `z9x_gapps`. Добавятся Google Play, сервисы Google Play,
синтез речи Google, TalkBack и пульт в приложении Google TV на телефоне. Chromecast
built-in не работает: сертификат Cast Google выдаёт только моделям, которые он сертифицировал. С iPhone,
iPad и Mac транслируйте по AirPlay.

Раздел с сервисами Google установщик собирает на компьютере, поэтому нужен Mac или компьютер с Linux
(x86-64 или ARM64) и около 1 ГБ свободного места. На Windows установщик сервисы Google пока не ставит и
останавливается, ничего не записав.

1. Скачайте MindTheGapps для 32-битного Android 14 TV (223 МБ). Нужен именно этот файл, другой установщик
   не примет:
   [MindTheGapps-14.0.0-arm-ATV-full-20240523_191930.zip](https://github.com/MindTheGapps/14.0.0-arm-ATV/releases/download/MindTheGapps-14.0.0-arm-ATV-20240523_192108/MindTheGapps-14.0.0-arm-ATV-full-20240523_191930.zip).
   Положите его в папку установщика, рядом с `lumen-install.sh`. Safari на Mac иногда сам распаковывает
   архив. Если так вышло, скачайте другим браузером: нужен именно `.zip`.
2. Выберите один из двух способов.

**Сразу при установке** (данные стираются один раз). На [шаге 5](#hb-install) запустите:

```
bash lumen-install.sh --lang ru --ip 192.168.x.y --gapps-zip MindTheGapps-14.0.0-arm-ATV-full-20240523_191930.zip
```

Установщик проверит файл, соберёт из него раздел с сервисами Google (10–30 секунд) и в том же заходе в
режим fastboot запишет его после системы, до стирания данных. Если раздел не поместился или не записался,
установщик удаляет его и заканчивает установку без Google. Тогда поставьте их вторым способом.

**Потом, на уже установленную Lumen OS** (данные стираются ещё раз). Включите отладку
([шаг 7](#hb-verify), пункты 1–3) и запустите:

```
bash lumen-install.sh --lang ru --ip 192.168.x.y gapps --zip MindTheGapps-14.0.0-arm-ATV-full-20240523_191930.zip
```

Введите `ERASE`, а когда установщик попросит, соедините USB-порт проектора с компьютером кабелем A–A. За
один заход в режим fastboot он запишет раздел `z9x_gapps`, сотрёт данные и перезагрузит проектор.

Войдите в Google в первой настройке или потом в «Настройки → Аккаунты». Если Google не пускает или Play
пишет, что устройство не сертифицировано, зарегистрируйте проектор:

1. Подключите проектор к интернету, включите отладку ([шаг 7](#hb-verify), пункты 1–3), а в разделе «Для
   разработчиков» ещё «Отладка суперпользователем».
2. Узнайте GSF ID:

   ```
   bash lumen-install.sh --lang ru --ip 192.168.x.y gsf
   ```

3. Зарегистрируйте его на [google.com/android/uncertified](https://www.google.com/android/uncertified),
   подождите 10–30 минут и войдите в «Настройки → Аккаунты».

Состояние сервисов Google показывает `bash lumen-install.sh --lang ru --ip 192.168.x.y gapps`. Убрать их
(тоже стирает данные): `bash lumen-install.sh --lang ru --ip 192.168.x.y gapps --remove`. Если Lumen OS два
раза подряд не смогла загрузиться с сервисами Google, следующий запуск идёт без них; команда `gapps`
покажет это и предложит включить их снова (для этого тоже нужна «Отладка суперпользователем»).

<a name="hb-rescue"></a>

## Ремонт: Lumen OS больше не загружается (данные сохраняются)

Если Lumen OS не может загрузиться до конца, через несколько минут проектор сам переходит в режим fastboot и
ждёт там. `rescue` заново записывает Lumen OS в тот слот, из которого он работает, без стирания данных:

1. Скачайте образ из самого нового релиза для HB, оба файла `SHA256SUMS` и архив установщика, как в
   [шаге 2](#hb-files). Старая система поверх новых данных может не загрузиться.
2. Запустите `bash lumen-install.sh --lang ru --device hb rescue` (Windows:
   `lumen-install.cmd rescue -Device hb -Lang ru`) и введите `WRITE`.
3. Когда установщик попросит, соедините USB-порт проектора с компьютером кабелем A–A.

Если обновление по Wi-Fi ещё не завершено, `rescue` ничего не записывает: запись тогда уничтожила бы путь
назад. Установщик показывает команды, при которых всё сохраняется (чаще всего `fastboot set_active` на
другой слот, затем `fastboot reboot`), и оставляет проектор в режиме fastboot. Введите их, как показано.

<a name="hb-problems"></a>

## Если что-то пошло не так

| Где | Что пишет установщик | Что делать |
|---|---|---|

| check | проектор … не разрешил отладку с этого компьютера | На проекторе разрешите отладку, отметьте «Всегда разрешать с этого компьютера» и нажмите OK. Запустите снова. |
| check | это не XGIMI Z9X HB (код модели …, плата …) | Установщик только для модели G0130. Ничего не сделано. |
| check | прошивка XGIMI … не поддерживается | Нужна ровно V6.16.24. Ничего не сделано. Если у вас другая версия, напишите об этом. |

| check | SHA256SUMS не подписан ключом Lumen OS, или контрольная сумма не совпала | Файлы испорчены или не с GitHub. Скачайте их заново из одного релиза для HB. |
| flash | текущий слот … всё ещё проверяет систему (*-verity в /dev/block/mapper) | Сделайте [шаг 4](#hb-vbmeta). Ничего не записано. |

| flash | system записан не полностью, или очистка (…) не удалась | Проектор остаётся в режиме fastboot. Не вынимайте кабель и запустите установщик снова. |

| Google | у установщика нет erofs-utils для этого компьютера | Сервисы Google ставятся с Mac или с компьютера с Linux. Ничего не записано. |
| rescue | 'rescue' ничего не записал: в слоте … не завершено обновление | Введите команды, которые он показал выше этой строки, см. [«Ремонт»](#hb-rescue). Проектор остаётся в режиме fastboot. |

Прогресс установки установщик хранит в `~/.lumen-installer/hb/`. Команда `bash lumen-install.sh status`
покажет его, `bash lumen-install.sh --device hb reset` сбросит. Проектор они не трогают.

Если ничего не помогло, напишите в [тему на 4PDA](https://4pda.to/forum/index.php?showtopic=1121837) или в
[issues на GitHub](https://github.com/kmuradoff/lumen-os/issues) и приложите:

- версию прошивки XGIMI и версию Lumen OS, если она уже стоит;
- что вы делали и на каком шаге всё остановилось;
- весь текст из терминала, а не скриншот;
- вывод `bash lumen-install.sh status`.

<a name="hb-stock"></a>

## Откат на сток (стирает всё)

Родную прошивку ставит собственное обновление XGIMI с флешки.

1. Скачайте официальную прошивку XGIMI V6.16.24 для модели G0130 с сервера XGIMI:
   [XGIMI_GOATELEGANT_XR03D.bin](https://product-library.static.xgimi.com/firmware/release/MTK9660_AOSP/dapeng/MTK9660_AOSP_GEMINI_6.16.24_20260428-152516/XGIMI_GOATELEGANT_XR03D.bin) (2,2 ГБ). Файл для другой модели не подойдёт.
   **Внимание: это 6.16.24**, только для возврата с Lumen OS, не для проекторов с прошивкой V6.17.12.
2. Флешка со схемой разделов **MBR** и **одним разделом FAT32**. На macOS: «Дисковая утилита → Вид →
   Показывать все устройства», выберите саму флешку (не её том), «Стереть», формат «MS-DOS (FAT)», схема
   «Основная загрузочная запись».
3. На флешке только два файла: `XGIMI_GOATELEGANT_XR03D.bin` (ровно с таким именем) и **пустой** файл
   `factory.txt`. На macOS копируйте в терминале, потому что Finder добавляет скрытые файлы `._`:

   ```
   cp -X ~/Downloads/XGIMI_GOATELEGANT_XR03D.bin /Volumes/STICK/
   ```

   ```
   touch /Volumes/STICK/factory.txt
   ```

4. Выньте кабель A–A. Вставьте флешку в USB-порт проектора (если ничего не происходит, попробуйте другой
   порт). Выньте кабель питания.
5. Зажмите кнопку питания проектора, вставьте кабель питания и держите кнопку 6–7 секунд. Без кнопки
   флешка ничего не делает.
6. Восстановление идёт несколько минут и стирает всё. Не отключайте питание. Если питание всё же
   пропало, оставьте флешку в порту и включите проектор снова. Потом загрузится родная система, как с
   завода.
7. Выньте флешку и удалите с неё `factory.txt`, чтобы прошивка не поставилась ещё раз случайно.

После отката проверка vbmeta снова включена. Чтобы поставить Lumen OS снова, начните с
[шага 1](#hb-prepare), а перед шагом 3 сбросьте прогресс прошлой установки:
`bash lumen-install.sh --device hb reset` (Windows: `lumen-install.cmd reset -Device hb`).

<a name="hb-changes"></a>

## Что меняется на проекторе

| Раздел | Что происходит |
|---|---|
| `system_a` | заменяется на Lumen OS |
| `userdata`, `metadata` | форматируются при установке |
| `z9x_blobs_a` (новый, 4 МБ) | два файла XGIMI с вашего проектора |
| `z9x_gapps_a` (новый, около 370 МБ) | только если вы ставите сервисы Google |
| `vbmeta` | меняете только вы, на шаге 4 |
| boot, vendor, product, system_ext, dtbo, второй слот, калибровка | установщик их не трогает |

Lumen OS распространяется по лицензии Apache-2.0. Программ XGIMI, MediaTek и Google в файлах релиза нет.

Lumen OS я делаю сам. XGIMI, Google и LineageOS к ней отношения не имеют. Ставите её на свой страх и
риск.

# Установка Lumen OS на XGIMI Z9X

Lumen OS 1.0 · для проекторов XGIMI · автор kmuradoff

Lumen OS заменяет Android от XGIMI на проекторе **XGIMI Z9X** (код модели `G0082`) быстрой системой
Android TV 14 (LineageOS 21 + сервисы Google TV) с новым главным экраном и обновлениями по воздуху.
Прошивка XGIMI, лампа, фокус, трапеция и ваша калибровка остаются как есть.

> Lumen OS — независимый проект. Его не делают, не одобряют и не поддерживают XGIMI, Google
> и LineageOS. Вы устанавливаете систему на свой риск. Как вернуть сток — в конце инструкции.

**Время:** около 25 минут. **Сложность:** нужно ввести несколько команд в терминале.

```
 1 Подготовка ─▶ 2 Проверка ─▶ 3 Копия ─▶ 4 vbmeta ─▶ 5 Установка ─▶ 6 Первый запуск ─▶ 7 Google
   10 мин         1 мин         5 мин      5 мин       3 мин          5 мин              5 мин
```

---

## Никогда не делайте этого (красная рамка)

| Никогда | Почему |
|---|---|
| `fastboot -w`, `fastboot erase userdata`, `fastboot erase metadata` | Z9X после этого зависает при загрузке, спасает только восстановление стока с флешки. Установщик очищает данные командой `format`, это безопасно. |
| Прошивать `vendor`, `boot`, `dtbo` и любые разделы, которых нет в установщике | Это прошивка XGIMI. Lumen OS её не меняет. |
| Блокировать загрузчик (`fastboot flashing lock`) | Проектор откажется запускать Lumen OS. |
| `adb reboot bootloader` | На Z9X эта команда просто выключает проектор. Используйте `adb reboot fastboot`. |
| Долгие паузы в режиме fastboot | Режим fastboot XGIMI сам выходит примерно через 2 минуты. Каждый шаг — одна короткая сессия. |
| Подключать сток к Wi-Fi во время подготовки (после шага 1) | Сток сам ставит обновления XGIMI во второй слот. |

---

## Что понадобится

- Проектор на **прошивке XGIMI V6.15.58** (Настройки > Об устройстве на стоке). Другие версии
  установщик не примет: сначала дайте стоку обновиться по Wi-Fi (шаг 1).
- Компьютер: **macOS или Linux** (полная поддержка) или **Windows 10/11** (бета, ещё не проверялась).
- **Android SDK Platform-Tools версии 35 или новее** (adb + fastboot):
  https://developer.android.com/tools/releases/platform-tools Распакуйте и добавьте папку в PATH.
  Файлы `make_f2fs` и `mke2fs` должны лежать рядом с `fastboot` (они есть в архиве): без них
  безопасная очистка данных невозможна.
- **Кабель USB A–A** для порта **USB 2.0** проектора.
- Файлы выпуска Lumen OS в одной папке: `lumen-os-<версия>-system.img`, `SHA256SUMS`,
  `SHA256SUMS.sig` и установщик (`lumen-install.sh`, `lumen-install.cmd`, `lumen-install.ps1`, `lib/`,
  `certs/`, `release.conf`).
- На всякий случай — **флешка для восстановления стока** (см. конец инструкции).

## 1. Подготовка проектора (10 мин)

1. На стоке убедитесь, что прошивка **V6.15.58** (при необходимости дайте ей обновиться по Wi-Fi),
   затем отключите Wi-Fi.
2. **Удалите аккаунт Google** на стоке (Настройки > Аккаунты). Иначе после очистки защита от сброса
   (FRP) может попросить его.
3. Включите **отладку по USB**. XGIMI прячет параметры разработчика; обычный путь — установить
   *SystemUI Tuner* с флешки (если файловый менеджер не принимает `.apk`, переименуйте файл в `.apk1`,
   как описано в теме сообщества), открыть в нём параметры разработчика и включить отладку по USB.
4. **Перезагрузите проектор** (отладка по USB начинает работать только после перезагрузки).
5. Подключите кабель A–A к порту **USB 2.0** проектора и к компьютеру.

## 2. Проверка (1 мин, ничего не записывает)

macOS / Linux:

```
cd lumen-os-1.0
bash lumen-install.sh --lang ru check
```

Windows: `lumen-install.cmd check -Lang ru`

На проекторе подтвердите **Разрешить отладку по USB** пультом (отметьте «Всегда разрешать»).
Проверка смотрит модель (G0082), прошивку XGIMI, программы на компьютере и образ: его контрольную
сумму и подпись Lumen OS на `SHA256SUMS`. Ничего не записывается.

Можно просто запустить `bash lumen-install.sh` без команды: он пройдёт шаги 2–6 по порядку, запомнит,
где остановился, и в следующий раз продолжит оттуда.

## 3. Резервная копия (по желанию, 5 мин)

```
bash lumen-install.sh backup
```

Копирует установленные приложения (файлы APK), папки Download/Movies/Music/Pictures/DCIM/Documents
и списки настроек в `~/Lumen-backup/<дата>/`. Данные приложений (входы, прогресс) без root сохранить
нельзя.

<a name="vbmeta"></a>

## 4. vbmeta: единственный ручной шаг (5 мин)

Lumen OS не подписана XGIMI. Поэтому проектору нужно **один раз** разрешить не проверять системный
раздел. Это стандартный шаг для любой системы Android «GSI», и **вы делаете его сами** по официальной
инструкции Google. Установщик никогда не выполняет команды vbmeta.

1. Откройте инструкцию Google: https://source.android.com/docs/core/tests/vts/gsi#flashing-gsis, раздел
   **«Requirements for flashing GSIs»**.
2. Войдите в fastboot командой `adb reboot fastboot` (не `bootloader`).
3. Прошейте неизменённый `vbmeta.img` от Google **с отключённой проверкой (verification disabled)**
   ровно так, как показано в инструкции, **для обоих слотов, A и B**, в этой одной сессии. Оба слота
   важны: тогда будущие обновления по Wi-Fi (они ставятся во второй слот) больше ничего не потребуют.
4. Перезагрузите. Сток загрузится как обычно. Снова подключите кабель.

Затем ответьте **да**, когда установщик спросит, сделан ли этот шаг.

**Уже на Lumen OS?** Настройки > Об устройстве > Обновление Lumen OS покажет, нужен ли этот шаг
второму слоту («Нужен разовый шаг для обновлений»). Оно читает заголовок vbmeta слота и никогда его
не записывает.

## 5. Установка (3 мин, СТИРАЕТ ВСЕ ДАННЫЕ)

```
bash lumen-install.sh flash
```

Сначала установщик проверяет образ: рядом с ним должны лежать `SHA256SUMS` и `SHA256SUMS.sig` из того
же релиза, подпись должна сойтись с сертификатом Lumen OS внутри установщика, а контрольная сумма —
с образом. Без них он останавливается (только собственные сборки автора ставятся с
`--unsigned-image`, и тогда нужно ввести `UNSIGNED`). Введите `ERASE`, когда установщик попросит;
в вопросе перечислены и удаляемые разделы XGIMI. За одну сессию fastboot (заметно меньше 2 минут)
установщик:

1. удаляет остатки незавершённых обновлений (`*-cow`) и неиспользуемые разделы XGIMI
   `product`/`system_ext` текущего слота;
2. записывает **system** (около 40 секунд);
3. только для публичных образов: записывает компоненты защищённого видео в `z9x_blobs` (см. ниже);
4. безопасно очищает данные: `fastboot format` раздела userdata (с теми же свойствами файловой
   системы, что у стока), metadata и cache. Никогда `-w`, никогда `erase`;
5. перезагружает проектор.

System всегда записывается **до** очистки: если fastboot прервётся раньше, проектор всё равно
загрузится (Lumen OS на старых данных), и вы просто запустите `flash` ещё раз.

Установщик трогает **только** system, z9x_blobs, userdata, metadata и cache текущего слота. Разделы
калибровки XGIMI (persist, xgimi*), прошивка, vendor, boot, vbmeta и второй слот не затрагиваются
никогда. Если на проекторе уже Lumen/Z9X OS, установщик ещё и записывает контрольные суммы разделов
калибровки до и после (только чтение) и сообщает, что они не изменились.

**Защищённое видео (публичные образы).** Кинопоиску HD и другому видео с DRM нужны файлы кодеков
MediaTek, которые мы не имеем права распространять. Шаг `blobs` копирует их с родной системы **вашего
собственного** проектора, сверяет каждый файл со списком известных контрольных сумм и кладёт в
маленький раздел `z9x_blobs`. Они переживают обновления и сброс к заводским настройкам. Копия
хранится в `~/Lumen-backup/blobs-<серийный>.img`. Личная сборка автора содержит их прямо в образе
(образы с именем `lumen-os-<версия>-PRIVATE-system.img`, установка с `--blobs=embedded`), поэтому там
этот шаг пропускается. Опубликованный установщик по умолчанию использует `BLOBS=partition` и
отказывается работать, если видит несоответствие. Если файлов кодеков вашей прошивки нет в списке
(шаг `blobs` остановится и скажет об этом), установить всё равно можно с `--no-blobs` (Windows:
`-NoBlobs`): работает всё, кроме защищённого видео.

**Если очистка не удалась** (`format` не принят): проектор загрузит Lumen OS на старых данных.
Тогда сделайте на проекторе *Настройки > Настройки устройства > Сброс > Сброс к заводским настройкам*
(или запустите установщик с `--wipe=factory-reset`).

## 6. Первый запуск (5 мин)

Первая загрузка занимает 2–4 минуты. Настройка спрашивает по порядку: **язык**, Wi-Fi, пульт, вход
в Google (можно пропустить), автофокус и трапецию, главный экран (Lumen Home или классический
лаунчер Android TV).

После очистки отладка по USB выключена (в Lumen OS она по умолчанию выключена, а подключение adb
требует подтверждения), поэтому `bash lumen-install.sh verify` проверит систему только после того,
как вы её включите. Это необязательно: на проекторе откройте *Настройки > Настройки устройства > Об
устройстве*, семь раз нажмите OK на *Сборка*, затем *Настройки > Настройки устройства > Для
разработчиков > Отладка по USB*. Подключите кабель и подтвердите на проекторе вопрос «Разрешить
отладку по USB?» (отметьте «Всегда разрешать с этого компьютера»).

## 7. Вход в Google (5 мин)

Lumen OS пока нет в списке сертифицированных устройств Google, поэтому один раз зарегистрируйте
устройство:

```
bash lumen-install.sh gsf
```

покажет ваш *GSF ID* (нужны отладка по USB и пара минут интернета). Введите его на
https://www.google.com/android/uncertified под своим аккаунтом Google, подождите 10–30 минут и войдите
на проекторе (Настройки > Аккаунты или шаг Google в настройке).

## Обновления по Wi-Fi

*Настройки > Настройки устройства > Об устройстве > Обновление Lumen OS* (или значок «Доступно
обновление» на Lumen Home).

- Обновления подписаны ключом выпуска Lumen OS; всё остальное отвергается.
- По умолчанию **обновление загружается автоматически, а устанавливается только после вашего
  согласия**. Можно выбрать «Только сообщать» или «Выкл».
- Обновление записывается во **второй** слот, пока вы смотрите. Перезагрузите, когда удобно; если
  новая версия не запустится правильно, проектор сам вернётся к предыдущей («Обновление не
  запустилось. Восстановлена Lumen OS x.y»).
- **Первое** обновление в слот один раз спросит, можно ли **скопировать без изменений** прошивку
  XGIMI в этот слот (boot, загрузчик, прошивки дисплея и звука, конфигурация). Собственные обновления
  XGIMI делают то же самое; ничего не изменяется, не расшифровывается и никуда не отправляется,
  vbmeta не записывается.
- Без интернета: скопируйте `update-stable.json`, `update-stable.json.sig`, файл `-ota.zip` и его
  `-payload_metadata.bin` в корень флешки и выберите *Установить с USB-накопителя*.

## Если что-то пошло не так

| Где | Что видно | Что делать |
|---|---|---|
| check | «нужно ровно одно устройство в adb» | Отладка по USB включена? Проектор перезагружали после её включения? Кабель A–A в порту **USB 2.0**? Подтвердили запрос на экране? `adb devices` должен показать ровно одно устройство. |
| check | «прошивка ... не поддерживается» | Дайте стоку обновиться до V6.15.58 по Wi-Fi и запустите снова. |
| check | «контрольная сумма не совпала» / «не подписан Lumen OS» | Скачайте выпуск заново. Никогда не устанавливайте образ, не прошедший эту проверку. |
| check | «нет make_f2fs/mke2fs» | Используйте официальный архив Platform-Tools; не разделяйте его файлы. |
| flash | «не появился в fastboot» | Подождите, переподключите кабель, запустите `flash` снова. Windows: установите драйвер Google USB. |
| flash | «ещё завершается обновление» | Дайте проектору загрузиться, подождите 10 минут и повторите. |
| flash | «system не записан» | Ничего не изменилось: загрузится старая система. Повторите; проверьте кабель. |
| первый запуск | Перезагружается по кругу | Скорее всего, шаг vbmeta (раздел 4) не сделан для этого слота. В цикле USB недоступен: восстановите сток с флешки (ниже) и начните заново с шага 1. |
| первый запуск | Настройка просит старый аккаунт Google | Защита от сброса: войдите в аккаунт, который был на стоке. |
| Google | «Устройство не сертифицировано Play Защитой» | Зарегистрируйте GSF ID (шаг 7) и подождите до 30 минут. |
| обновления | «Нужен разовый шаг для обновлений» | Второму слоту нужен шаг vbmeta (раздел 4), с компьютера. |
| обновления | «Нет компонентов защищённого видео» | Запустите `bash lumen-install.sh blobs` и `bash lumen-install.sh flash --keep-data` (публичные образы). |

Установщик хранит прогресс в `~/.lumen-installer/`; `bash lumen-install.sh status` покажет его,
`reset` сбросит.

## Возврат на сток (стирает всё)

1. Получите родную прошивку `.bin` для Z9X в поддержке XGIMI (мы её не распространяем).
2. Подготовьте флешку: **FAT32, MBR**. Скопируйте на неё `.bin` и пустой файл `factory.txt`.
3. Отключите кабель A–A. Вставьте флешку в порт **USB 2.0**.
4. Включите проектор, удерживая кнопку питания 6–7 секунд.
5. Восстановление занимает около 4 минут и стирает всё. Затем загрузится сток.

## Для любопытных: что именно меняется

| Часть | Меняется? |
|---|---|
| `system` (текущий слот) | Заменяется на Lumen OS |
| `userdata`, `metadata`, `cache` | Один раз очищаются (форматируются) при установке |
| `z9x_blobs` (новый, 4 МБ, публичные образы) | Ваши собственные файлы кодеков MediaTek |
| `product`, `system_ext` (XGIMI, не используются Lumen OS) | Удаляются при установке (освобождается 164 МБ) |
| `vbmeta` | Только вами, вручную, по инструкции Google |
| boot, vendor, dtbo, mboot, optee, tvconfig, persist, xgimi*, калибровка | Никогда |
| Второй слот | Только обновлением Lumen OS, которое вы подтвердили (записывается system, прошивка XGIMI копируется без изменений) |
